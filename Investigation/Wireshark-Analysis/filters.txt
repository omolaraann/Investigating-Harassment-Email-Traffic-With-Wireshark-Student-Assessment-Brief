CASE STUDY 1: INVESTIGATING HARASSMENT EMAIL TRAFFIC WITH WIRESHARK

WIRESHARK ANALYSIS FILTERS
============================================================

Purpose:
This file documents the Wireshark display filters used during the
analysis of the Nitroba network traffic capture.

All filters were applied to the original nitroba.pcap evidence unless
otherwise stated.

------------------------------------------------------------
1. IDENTIFY HTTP GET REQUESTS TO WILLSELFDESTRUCT.COM
------------------------------------------------------------

Filter:

http.request.method == "GET" && http.host == "www.willselfdestruct.com"

Purpose:
Identifies HTTP GET requests made to the willselfdestruct.com web
service.

Relevant Finding:
Frame 82936 showed the client at 192.168.15.4 requesting:

GET /secure/submit HTTP/1.1

Destination:
69.25.94.22

Note:
Frame 82936 establishes interaction with the secure submission
endpoint. It is not itself the harassment message submission.

------------------------------------------------------------
2. IDENTIFY THE HTTP POST REQUEST
------------------------------------------------------------

Filter:

http.request.method == "POST" && http.host == "www.willselfdestruct.com"

Purpose:
Identifies HTTP POST requests submitted to the willselfdestruct.com
web service.

Relevant Finding:
Frame 83601 contained the relevant POST request:

POST /secure/submit HTTP/1.1

Source IP:
192.168.15.4

Destination IP:
69.25.94.22

The POST request contained the recipient, subject, and harassment
message identified during packet analysis.

------------------------------------------------------------
3. IDENTIFY THE CLIENT AND WEB SERVICE COMMUNICATION
------------------------------------------------------------

Filter:

ip.src == 192.168.15.4 && ip.dst == 69.25.94.22 && http.request.method == "POST"

Purpose:
Correlates the relevant HTTP POST request with the client IP address
and destination web service.

Relevant Finding:
Frame 83601 was generated by client IP 192.168.15.4 and sent to
69.25.94.22.

------------------------------------------------------------
4. IDENTIFY THE DEVICE USING THE SOURCE MAC ADDRESS
------------------------------------------------------------

Filter:

eth.src == 00:17:f2:e2:c0:ce

Purpose:
Identifies traffic originating from the Ethernet source MAC address
associated with the relevant client device.

Relevant Finding:
The source MAC address associated with the harassment submission was:

00:17:f2:e2:c0:ce

Frame 83601 contains this source MAC address together with client IP
192.168.15.4.

------------------------------------------------------------
5. CORRELATE THE MAC ADDRESS WITH THE WEB SERVICE
------------------------------------------------------------

Filter:

eth.src == 00:17:f2:e2:c0:ce && ip.dst == 69.25.94.22

Purpose:
Restricts traffic to packets originating from the identified source
MAC address and communicating with the willselfdestruct.com service.

Relevant Finding:
The filter returned traffic from the identified device to the web
service. Frame 83601 was used to correlate the device with the
harassment POST request.

------------------------------------------------------------
6. IDENTIFY BROWSER COOKIE / ACCOUNT EVIDENCE
------------------------------------------------------------

Filter:

eth.src == 00:17:f2:e2:c0:ce && http.cookie contains "@"

Purpose:
Searches HTTP traffic originating from the identified device for
cookies containing an email-address indicator.

Relevant Finding:
Frame 79187 contained the following relevant cookie pair:

gmailchat=jcoachj@gmail.com/475090

The packet originated from client IP 192.168.15.4 and was associated
with source MAC 00:17:f2:e2:c0:ce.

------------------------------------------------------------
7. SEARCH FOR SECURE ANONYMOUS EMAIL CONTENT
------------------------------------------------------------

Filter:

data-text-lines contains "secure anonymous E-mail"

Purpose:
Searches packet data for text associated with the secure anonymous
email service.

Use:
This filter was used during initial traffic exploration to locate
relevant application-layer content associated with the harassment
email service.

------------------------------------------------------------
8. IDENTIFY ALL TRAFFIC FROM THE CLIENT
------------------------------------------------------------

Filter:

ip.src == 192.168.15.4

Purpose:
Examines traffic originating from the client system identified during
the investigation.

Use:
Supports correlation of the client IP with HTTP activity and other
network communications.

------------------------------------------------------------
9. IDENTIFY THE RELEVANT POST BY CLIENT IP AND MAC
------------------------------------------------------------

Filter:

eth.src == 00:17:f2:e2:c0:ce && ip.src == 192.168.15.4 && http.request.method == "POST"

Purpose:
Provides a more specific correlation between the Ethernet source MAC,
client IP address, and HTTP POST activity.

Use:
Supports the conclusion that the device associated with MAC
00:17:f2:e2:c0:ce generated the relevant HTTP POST traffic.

------------------------------------------------------------
10. FRAME REFERENCES
------------------------------------------------------------

Frame 82936:
HTTP GET /secure/submit
Client: 192.168.15.4
Server: 69.25.94.22
Purpose: Establishes interaction with the submission endpoint.

Frame 83601:
HTTP POST /secure/submit
Client: 192.168.15.4
Server: 69.25.94.22
Source MAC: 00:17:f2:e2:c0:ce
Purpose: Contains the actual harassment message submission.

Frame 79187:
HTTP cookie traffic
Client: 192.168.15.4
Source MAC: 00:17:f2:e2:c0:ce
Relevant cookie:
gmailchat=jcoachj@gmail.com/475090
Purpose: Provides browser/session-level association between the
identified device and the Gmail account.

------------------------------------------------------------
ANALYTICAL CAUTION
------------------------------------------------------------

The filters identify network and browser/session relationships.
They do not independently establish the physical identity of the
person operating the device.

The case scenario states that the wireless network was open and
could be accessed by multiple people. Therefore:

IP address alone does not identify the sender.

MAC address identifies the observed network interface/device but does
not establish who was operating it.

A browser cookie provides an association with an account/session but
does not by itself prove that the account owner was physically using
the device at the exact time of the harassment submission.

The final attribution assessment therefore combines the network
evidence, browser/session evidence, and Chemistry 109 roster evidence
while preserving these limitations.
