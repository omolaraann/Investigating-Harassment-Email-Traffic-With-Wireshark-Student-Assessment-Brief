------------------------------------------------------------
WHY THE IP ADDRESS ALONE IS NOT SUFFICIENT
------------------------------------------------------------

The case scenario states that the dormitory wireless router was
installed as an open, passwordless wireless network.

As a result, multiple people could access the same wireless network.

A shared network connection can cause traffic from different users
to appear through the same network-level IP address.

Therefore, the fact that the harassment request originated from
192.168.15.4 does not independently establish which individual
generated the traffic.

The IP address establishes the network source observed in the PCAP,
not the identity of the human operator.

------------------------------------------------------------
ROLE OF THE MAC ADDRESS
------------------------------------------------------------

The source MAC address provides a more specific network-level
identifier for the interface observed in the captured Ethernet frame.

However, the MAC address should not be treated as proof of human
identity.

A MAC address identifies the network interface/device observed in the
capture. It does not establish who was physically operating that
device at the time of the event.

Consequently, the MAC address strengthens device-level attribution
but must be correlated with additional evidence for individual
attribution.

------------------------------------------------------------
CONCLUSION FOR QUESTION 4
------------------------------------------------------------

The relevant request was made by the network interface/device observed
with source MAC address 00:17:f2:e2:c0:ce and client IP address
192.168.15.4.

The shared IP address alone cannot prove the identity of the sender
because the case scenario describes an open wireless network that
could be accessed by multiple users.

The MAC address establishes a device-level association, but additional
browser/session and contextual evidence is required before making an
individual attribution.
